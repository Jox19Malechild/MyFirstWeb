Projects and Skills

Three things I have learned so far. Use the buttons to open or close the details.

HTML page structure

I can build a page with header, nav, main, sections and footer.

I learned to use semantic tags, lists, tables, images with alt text, and audio and video with controls. This site is built from these parts.

CSS styling and layout

I can style a page so it looks good on phones and computers.

I learned colours, spacing with the box model, Flexbox, Grid, hover and focus states, and media queries for small screens.

JavaScript interaction

I can make a page respond when a visitor clicks or types.

I learned variables, functions, events and DOM updates. On this site I used them for form validation, a theme switch, a photo viewer and these expandable details.
